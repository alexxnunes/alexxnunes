## 💻 Sobre mim

Sou desenvolvedor de software em formação, com foco em backend, infraestrutura e DevOps.
Minha base principal é Java e Spring Boot, com experiência prática em Docker, Linux,
Nginx e Oracle Cloud Infrastructure para deploy e gerenciamento de aplicações —
da arquitetura do backend e banco de dados até deploy e documentação. No frontend,
trabalho com JavaScript, HTML e CSS.

Minha formação inclui o programa **Oracle Next Education (ONE)** em parceria com a **Alura**

Git/GitHub, desenvolvimento web e Spring Boot.

conformidade com a LGPD nos projetos que desenvolvo.
